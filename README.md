# GreenAudit EnergyPlus Studio

GreenAudit EnergyPlus Studio is a lightweight, front-end energy auditing application that highlights a full EnergyPlus simulation workflow. It captures facility inputs, assembles EnergyPlus-ready modeling steps, and summarizes audit-ready outputs.

## Features
- Guided audit input form for building, HVAC, and operational details.
- EnergyPlus simulation workflow checklist with QA/QC coverage.
- Results dashboard with baseline/ECM scenario outputs.
- Downloadable audit report action (demo placeholder).

## Run locally
Open `index.html` in a browser. The UI is fully client-side.
